# M. Vamshi Kumar - Portfolio Website

Professional portfolio website for M. Vamshi Kumar, Electrical Engineering student and Research Author.

## Live Demo

[View Portfolio](https://mvamshi-kumar17.github.io/mvamshikumar-portfolio/)

## Features

- Fully responsive design (mobile, tablet, desktop)
- Dark / Light theme toggle with persistence
- Smooth scroll animations (AOS)
- Typing effect hero section
- Animated counters
- Contact form integration (FormSubmit)
- Timeline journey section

## Project Structure

```
├── index.html          # Main HTML page
├── css/
│   ├── style.css       # Main entry (imports all modules)
│   ├── variables.css   # CSS custom properties
│   ├── base.css        # Reset, typography, animations
│   ├── navbar.css      # Navigation styles
│   ├── hero.css        # Hero section
│   ├── sections.css    # All content sections
│   ├── theme.css       # Light/dark mode
│   └── responsive.css  # Media queries
├── js/
│   └── script.js       # Modular JavaScript (PortfolioApp)
├── images/             # Profile & project images
└── resume/             # Resume & certificates (PDF)
```

## Technologies

- HTML5, CSS3 (Modular Architecture)
- Bootstrap 5.3
- JavaScript (ES6+)
- Font Awesome 6
- AOS Animation Library
- Typed.js
